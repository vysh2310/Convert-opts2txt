# Polyspace `.opts` to Strict Options Converter

## 🔍 Overview

This repository provides a production-grade Python utility to convert Polyspace `.opts` files generated by `polyspace-configure` into a strict, one-option-per-line options file that can be used directly with the Polyspace command line.

This utility is designed for:
- Debugging reproducibility issues  
- Stabilizing analysis workflows  
- Automating Polyspace execution in CI/CD  
- Handling complex BSP/toolchain environments (e.g., Xilinx, ARM GCC)

---

## ✅ What the Script Does

The script performs the following:

 - Extracts:
- `-I` → Include paths  
- `-D` → Defines  
- `-U` → Undefines  
- Deduplicates extracted options globally  
- Preserves global options:
- `-sources`, `-lang`, `-compiler`, `-target`, etc.  
- Generates:
- CLI-ready strict options file  
- Log file  
- Diagnostics report
